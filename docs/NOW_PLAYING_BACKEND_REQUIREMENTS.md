# Экран «Сейчас играет»: состояние интеграций

В этом документе зафиксированы границы текущей реализации и оставшиеся интеграции экрана `mcrate-app/src/ui/now_playing.rs`.

## 1. Непрерывная аудиоволна — реализовано 16.11.2026

В `mcrate-audio/src/visualizer.rs` добавлен `AnalyzedSource`: прозрачная обёртка над декодером rodio, которая передаёт исходные сэмплы без изменения и раз в ~8,3 мс считает FFT последних 2048 сэмплов (окно Хэнна, свой FFT без зависимостей) и публикует 128 полос спектра (45 Гц ... 16 кГц, шкала логарифмическая) в атомарный массив.

- `PlaybackEngine::visualizer()` возвращает копию снимка, не блокируя аудиопоток.
- `Controller::visualizer()` передаёт снимок экрану.
- Анализатор работает и для локальных файлов, и для докачиваемых онлайн-потоков, поскольку включён на общем пути `AudioPlayer`.
- При смене трека, перемотке и остановке окно очищается; пауза оставляет последний кадр неподвижным.
- Уровень НЕ зависит от ползунка громкости плеера (в том числе от mute): анализатор видит исходный сигнал трека.
- Это настоящий спектр: индекс 0 это низкие частоты, 127 высокие, форма не ползёт вбок (раньше была лента громкости по времени, справа налево, от неё отказались 16.11.2026).

Публикация использует атомарные значения без mutex и выделений памяти в аудиопотоке. Визуальная плавность дополнительно сглаживается в UI.

## 2. Текст песни

В `mcrate_core::Track` сейчас есть только id, сервис, название, исполнители и длительность. В `MusicProvider` нет метода получения текста песни, и в текущих провайдерах источник текстов не реализован.

Для настоящих текстов нужен согласованный контракт с указанием источника/провайдера и результата (обычный текст или синхронизированные строки с временными метками). До появления этого контракта правая панель показывает честное состояние «Текст пока недоступен».

## 3. Очередь

Текущий `PlaybackState` уже содержит `queue_index` и `queue_len`, поэтому UI показывает позицию текущего трека в очереди. Для списка следующих треков потребуется отдельный read-only snapshot элементов очереди; UI не должен владеть второй копией очереди или менять её самостоятельно.

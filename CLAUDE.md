# Mcrate

Десктопный плеер для Windows 11 на Rust: Yandex Music, VK Music, SoundCloud, Spotify, локальные файлы. Только клиент, своих серверов нет. Работают LomKich1 и P1tr0v1ch.

Отвечай по-русски, коротко и по делу. Не знаешь или не уверен (особенно про неофициальные API): так и скажи. Если я ошибаюсь, возражай с аргументами. Незнакомые функции и строки в коде комментируй, термины расшифровывай в скобках.

**Этот файл не журнал.** Историю, даты и «почему сделано так» сюда не писать: им место в сообщении коммита и комментариях кода. Менять файл, только если изменилось правило или список задач.

## Главное правило: движок первым
Логика звука, очереди, кэша, хранения, сети и токенов живёт в крейтах и пишется с тестами; `mcrate-app` только подключает и рисует. Не хватает метода: добавь в движок, не обходи в UI. Если просьба идёт против этого, скажи до кода.

## Где что лежит
- `mcrate-core`: общие типы, `MusicProvider`, `TokenStore`, лайки, плейлисты, история, пути.
- `mcrate-audio`: `PlaybackEngine` (контракт в комментариях `engine.rs`), очередь, кэш.
- `mcrate-net`: HTTP, скачивание, HLS.
- `mcrate-providers`: локальные файлы, SoundCloud.
- `mcrate-app/src`: `controller.rs` (связь с движком), `theme/`, `ui/`.
- `ui/widgets/`: одиночные виджеты; `ui/components/`: общие блоки; `ui/home/`, `ui/settings/`: экраны.
- `vendor/egui_glass`: изменённая копия (см. `MCRATE.md` внутри).

Стек: eframe/egui 0.37 (wgpu), egui_glass 0.2, material-colors, rodio 0.23, Rust 1.95+.

## Код
- Функция до 60 строк (дольше только отрисовка или численный цикл, с объяснением в `///`), параметров до 5-6, иначе структура.
- Material 3 и Liquid Glass рисуются разными функциями; значения темы кладём в `Theme`.
- Повторяющийся код выносить. Списки треков только через `components::track_list`.
- Числа в отрисовке: именованные константы с `///`.
- Видимость `pub(crate)`/`pub(super)`; импорты внутри UI через `crate::ui::...`.
- Комментарии по-русски: `//!` у модуля, `///` у `pub(crate)` элементов и констант; объясняют «зачем».
- Загрузка в UI: `widgets::loading_indicator`.
- Окончания строк LF.

## Нельзя
- Писать токены и секреты в код, репозиторий, логи и ошибки (включая URL с `?...`). Токены только через `TokenStore`, в тестах выдуманные. Музыку в репозиторий не класть.
- Менять порядок слоёв (`glide_begin`/`glide_end`, щиты), `ui.new_child`, `skip_ahead_auto_ids`, `frame_time` без необходимости. Вместо `Id::new` использовать `Id::unique`.
- Добавлять побочные эффекты в замыкание страницы Liquid Glass (вызывается дважды за кадр).
- Включать `with_seekable(true)` для MP4 (паника декодера).
- Ставить общий `.timeout` на HTTP: только `connect_timeout` и `read_timeout`.
- Ходить в сеть провайдерами из `current_thread`: нужна общая долгоживущая многопоточная среда tokio.
- Удалять из кэша играющий, грузящийся или подготовленный трек.
- При рефакторинге менять поведение и внешний вид. Найденный баг сначала назвать, чинить после согласия.
- В M3 намеренно нет заливки карточек «Быстрый выбор» и «Мои треки» и наведения на карточках полок.

Изменения вида проверять для обеих тем.

## Проверка правок
- Мелкая правка (текст, отступ, цвет, константа, пара строк без смены сигнатур): Rust не ставить, тесты не запускать. Написать «сборкой не проверено».
- Крупная (новая логика, несколько файлов, типы, сигнатуры):
  `sh tools/setup_rust.sh && . /home/claude/env.sh && timeout 290 cargo check -p <крейт> --all-targets`
  Не уложилось: запустить ту же команду ещё раз.
- Тесты: только если менялась логика, и только в затронутом крейте. Известное падение: `material3_presets_have_complete_readable_schemes`.
- Окна и GPU нет: не утверждай, что проверил вид или звук.
- Сомневаешься, мелкая ли правка: спроси.

## Передача правок и git
- Правки отдавать архивом только с изменёнными файлами (пути от корня). Удалённые файлы назвать отдельно.
- После распаковки: `cargo clean -p <крейт>`, затем `cargo build`.
- Ветка одна, `main`. Перед работой `git pull`. После правки: `cargo build`, `git status` (нет ли секретов), `git add .`, `git commit -m "..."`, `git pull`, `git push`. Напомни об этом один раз в конце.
- Без согласия не использовать `push --force` и `reset --hard`. Коммиты маленькие.

## Поиск по коду

Для большой задачи можно Graphify: `pip install graphifyy --break-system-packages -q && graphify extract . --code-only --cargo --no-label`, затем `graphify query "вопрос" --budget 1500`. `graphify-out/` в архивы не класть.

## Задачи
- SoundCloud: получать трек по id (`get_stream` знает только недавно найденные).
- После конца очереди кнопка «играть» не перезапускает её.
- Не подключены настройки: качество стриминга, автовоспроизведение, язык, `wave_quality`, `cover_morph`.
- VK: сначала пробник на ПК, потом провайдер. Токены и экран подключения сервисов.
- Позже: Yandex Music (нужна подписка), Spotify (последним), «Волна», встроенный AmneziaWG; YouTube только плагином на yt-dlp.
- Нет настоящих обложек и текстов песен.
